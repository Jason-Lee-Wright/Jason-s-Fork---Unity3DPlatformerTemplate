## New Mechanic (Added by Jason Wright)

The mechanic I chose to add was a glide. If you hold G on your keybord (sorry there is no controller support) then you will gain 1 second of glide time.
This is great if you need that split second to think while in the air. The level is the same as my dash tutorial as i felt is was still a good place to learn the glide, and how it can interact with another mechanic that effects the players gravity for moment!
